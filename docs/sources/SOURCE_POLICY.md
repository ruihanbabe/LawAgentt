# LawAgent 信源与证据规则

## 信源用途

| 信源 | 允许用途 |
|---|---|
| 已核验官方法规 | 在已核验法域和有效期内支持法律主张 |
| 版本化法规快照 | 支持有限分析，同时展示快照和有效性警告 |
| 已脱敏案例记录 | 说明类似争议，不证明一般法律规则或胜诉概率 |
| 已核验公开模板 | 只在已核验适用范围内支持文书结构 |
| 未核验网页、搜索摘要或模型记忆 | 只生成检索候选，不得成为最终证据 |

## 硬约束

- 每项实质性法律主张必须引用当前 DeliveryGate 契约接受的证据。
- 案例证据不能替代法规证据证明一般法律规则。
- 缺失的法院、案号、日期、URL、权威等级或有效性信息必须保持缺失。
- 法规有效期使用版本标识和半开区间：存在结束日期时满足 `effective_from <= event_date < effective_to`。
- 原始 Provider/Qdrant payload 不得进入 Agent 上下文、API 输出、日志或 Trace。
- 用户案件内容不得写入共享知识库、Prompt、fixture 或公共评测数据。
- 历史集合数量和评测分数不是当前证据；需要验证时必须重新查询并记录当前 Schema/版本。

## 当前实现边界

Runtime 已有安全案例/法规 Evidence View 和可选 Qdrant Adapter。仓库当前没有原 ingestion/evaluation pipeline，也没有已经验证的实时数据 manifest。不得根据 Adapter 代码或 mock 推断数据完整性、集合健康或法律正确性。
