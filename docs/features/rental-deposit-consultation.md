# Feature Spec: Residential Rental Deposit Consultation
> 摘要：定义中国大陆个人住宅承租人押金拒退/少退/拖延场景的完整 MVP 行为。
> 摘要：功能覆盖准入、两轮受控追问、法规与案例检索、证据受限分析、材料和行动建议。
> 摘要：事实按场景准入、初步分析、行动/文书三层收集；不使用一次性完整问卷。
> 摘要：文书建议仅由用户主动触发，以文字返回模板来源、必要项、金额项目、防遗漏和带占位符草稿。
> 摘要：每项实质性主张绑定证据；快照、冲突、缺口和数据限制必须可见。
> 摘要：实现仍待远程核验；本文是产品行为契约，不记录未经验证的源码状态。

## 1. Feature 状态

- ID：`residential-rental-deposit-consultation`
- 状态：产品范围已确认；实现待远程核验。
- 目标：用一条真实纵向路径证明 LawAgent Harness 的受控执行、RAG、Review、Trace 与故障降级。

## 2. 支持边界

支持：中国大陆、个人承租住宅、租赁已结束或即将结束、押金拒退/少退/拖延、用户寻求沟通与维权准备。

排除：非住宅、组织承租、转租/群租、境外房产、买卖定金和高风险安全主路径。命中排除项时明确范围并有限回答。

## 3. 用户任务

1. 理解房东扣留押金可能涉及的争点和缺失事实；
2. 获得法规与相似案例支持的初步分析；
3. 获得证据/材料清单和分级下一步；
4. 主动请求时获得文本式文书建议。

## 4. 事实层级

### 4.1 场景准入

- 中国大陆住宅租赁；个人承租人；租赁结束/即将结束；押金争议；当前目标。

### 4.2 初步分析

- 押金金额；拒退/少退/拖延表现；房东理由；合同押金约定；交房/钥匙；欠费；损坏争议；现有证据。

### 4.3 行动与文书

- 双方身份/联系方式；房屋地址；合同和退租日期；已付/已退/争议金额；催告记录；履行期限；送达对象。

文书层事实不得阻塞咨询。未知合同约定允许继续，但降低结论强度。

## 5. 追问策略

- 首轮询问会改变准入、检索或核心争点的问题；第二轮补足有限分析。
- 每轮合并 2–3 个相关、高信息增益问题；不重复询问用户明确不知道的内容。
- 总澄清预算两轮；达到预算后输出已知事实、缺失项和一般建议。
- 信息充分性按阶段计算，不使用全局单一布尔值。

## 6. 检索与分析

- 法规与案例并行检索；结果经 rerank、来源策略和 Evidence Adapter。
- 法规为空时不输出确定法律结论；案例为空时可基于法规有限分析。
- 法规版本冲突或时效不明时展示冲突并建议权威复核。
- 案例必须说明相似与差异，不能直接推导胜诉或普遍裁判结果。

## 7. 最终交付

完整输出遵循 Requirements 的十段结构。每个实质性 Claim 绑定 Evidence；Evidence 卡片展示来源类型、相关摘录、locator、快照/有效期和限制。

系统不得把候选事实写成确认事实，不得补造法院、案号、日期、官方 URL、权威等级或金额。

## 8. 金额与文书建议

- 金额候选项目可由 Agent 识别，但计算由确定性工具执行并展示输入、公式、规则版本和缺失项。
- 文书建议由用户显式触发，只以文字返回。
- 输出包含模板来源与引用、必要项、建议项、可选项、缺失项、防遗漏和带 `[待补充]` 的草稿。
- 模板源为空时只给通用必要项检查，不伪造模板或来源。
- 不导出、不签名、不发送，不声称是可直接提交的正式起诉状。

## 9. 失败行为

失败矩阵以 `SYSTEM_DESIGN.md` 为准。该 Feature 的关键要求：Review 或 Trace 失败时不交付开放式法律分析；引用失败时删除主张或重做；过载时有界拒绝；所有降级可见且进入 Trace。

## 10. 验收场景

1. 简短“房东不退押金”触发高信息增益追问；
2. 已提供退租、扣款理由、合同与证据时进入检索；
3. 两轮后仍不足时有限回答且不循环；
4. 法规+案例成功时生成带主张级引用的十段回答；
5. 案例为空、法规为空、版本冲突分别按契约降级；
6. 候选事实不会进入 ConfirmedFact；
7. 金额缺输入不输出估算；
8. 未主动请求时不生成文书；主动请求且模板源为空时明确降级；
9. 商铺、公司承租或境外房产不进入押金主路径；
10. 两个以上并行 Matter 不串状态、证据和 Trace；
11. Provider 超时、Review 失败和 Trace 失败符合 fail-closed；
12. WebUI/API 真实入口完成至少一条成功与一条失败 E2E。

## 11. No-gos

文件上传、实时法规、胜诉概率、自动诉讼价值判断、正式文书导出、外部发送、长期画像、第二法律场景和生产级高并发。

## 12. 远程核验项

现有 Intent/Runtime/Node/Tool/Qdrant/前端字段、模型、持久化、测试和运行命令；核验后通过兼容映射或 ADR 更新契约，不得静默覆盖。
