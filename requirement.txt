# LawAgent 当前环境与依赖台账

## 当前解释器

- Conda 环境：`agent`
- Python：3.11.15
- 路径：`/root/miniconda3/envs/agent/bin/python`
- pip：26.1.2
- 环境性质：LawAgent 独立 Conda 环境
- 计算资源：8 CPU、43 GB 内存、RTX 3090 24GB；宿主终端 CUDA 可用，Codex 默认沙箱不映射 GPU 设备节点

## 当前环境结论

- 已有 Python 3.11 独立环境，可直接作为当前开发环境。
- FastAPI、Qdrant Client、FlagEmbedding、Sentence Transformers、Torch 等已安装。
- LangGraph、LangChain、LangChain OpenAI 与 RAGAS 尚未安装；它们不作为当前 MVP 依赖。旧 Agent/API 原型仍依赖 LangGraph/LangChain，暂作历史原型，当前开发转向自研轻量 Agent Runtime。
- 环境包含 CUDA 版 Torch。2026-08-04 宿主终端核验 `nvidia-smi` 与 PyTorch CUDA 正常，并使用 RTX 3090 完成 66,448 条法规向量入库；Codex 默认沙箱仍因设备隔离不可见。代码使用 `device=auto|cpu|cuda`。
- 不直接把完整 `pip freeze` 当作顶层依赖；待依赖选型稳定后生成锁定文件。
- Docker Engine 已从官方 Ubuntu Jammy APT 仓库安装并完成容器运行验证。当前环境无可用 systemd bus，daemon 使用项目专用目录和 Unix socket 手动运行。

## 系统运行依赖

| 能力 | 当前版本 | 当前运行方式 |
|---|---:|---|
| Docker Engine / CLI | `29.7.1` | daemon 手动启动；`data-root=/root/lawagent/.runtime/docker-data` |
| Docker Compose | `v5.4.0` | Docker CLI 插件 |
| containerd | `2.2.6` | 由 Docker daemon 使用 |
| Qdrant Server | `1.18.2` | `compose.yaml` 固定镜像；collections `laws_collection`、`cases_collection` |

当前 Docker 客户端连接变量：

```bash
export DOCKER_HOST=unix:///tmp/lawagent-docker.sock
```

该 socket 位于 `/tmp`，服务器或任务环境重启后需要重新启动 daemon；不得改成无认证的 TCP 监听。

## 依赖维护约定

1. `requirements.txt` 只列顶层运行依赖；后续增加 `requirements-dev.txt` 管理测试和质量工具。
2. 每次安装、升级或删除包，同步更新本文件的日期、原因和验证结果。
3. 锁定文件由工具生成，不手工编辑；候选方案为 `uv.lock`。
4. 禁止把 API Key、服务器绝对路径或本地模型文件写入依赖文件。
5. Python、Qdrant 和模型版本均视为运行时依赖，必须在开发说明中记录。
